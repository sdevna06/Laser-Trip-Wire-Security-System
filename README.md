# Laser Trip Wire Security System

## Project Overview

This project is an Arduino-based laser trip wire security system designed to detect intrusions using a laser beam and LDR sensor.

When the laser beam is interrupted, the Arduino activates a buzzer alarm.

---

## Components Used

- Arduino UNO
- Laser Module
- LDR Sensor
- Buzzer
- Breadboard
- Jumper Wires

---

## Features

- Intrusion detection
- Automatic alarm system
- Low-cost security solution
- Easy Arduino implementation

---

## Working Principle

The laser beam continuously falls on the LDR sensor.

If someone crosses the laser path, the beam gets interrupted.  
The Arduino detects the change in light intensity and activates the buzzer alarm.
